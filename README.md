# Financial Market Dashboard

A responsive dashboard that pulls live cryptocurrency data from the CoinGecko API, designed to handle real-time data fetching, loading states, and API errors gracefully.

## Features
- Live data fetching from a public REST API
- Responsive CSS grid (3 columns on desktop, 1 on mobile)
- Loading and Error states with a Retry button
- Automatic color coding for 24h price changes (green for gains, red for losses)

## Stack
HTML, CSS, JavaScript (Fetch API)
